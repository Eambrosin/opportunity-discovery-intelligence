# v1.0.0 — Evidence-Aware Opportunity Discovery Intelligence

## Release Summary

The first stable portfolio release of **Opportunity Discovery Intelligence**, the IDENTIFY layer of the Commercial Intelligence workflow.

This release turns public-web market research into a structured target-account discovery and qualification-preparation process.

## Commercial Design Principles

The release separates:

- account attractiveness from research completeness
- observed evidence from commercial interpretation
- qualification questions from unsupported claims
- public contact candidates from verified purchasing authority

A high-opportunity account is not automatically treated as a buying account.
